# Папка историй GiC_OS

Здесь лежат истории, созданные в редакторе GiC_OS («Своя история в GiC_OS» в главном меню).
В собранной игре эта папка находится рядом с исполняемым файлом. На Android и консолях она лежит в папке пользователя.

Одна история — одна папка:

```
stories/
  моя_история/
    story.json      — название, автор, стартовая метка, главы, возрастная маркировка
    main.gics       — сценарий (можно разбить на несколько .gics)
    assets/         — свои картинки (PNG, JPG) и звуки (OGG)
```

Пути к ассетам в сценарии ищутся сначала в `assets/` истории, потом во встроенных ассетах игры.
Например, `"old2023/images/os/bg desktop.png"` — бирюзовый рабочий стол из оригинала.

Формат сценария описан в [docs/GICS_FORMAT.md](../docs/GICS_FORMAT.md). Готовый пример — `example_story/`.
