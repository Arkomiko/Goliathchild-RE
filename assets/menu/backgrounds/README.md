# Фоны главного меню

Фон меню меняется по мере прохождения сюжета, как в Portal 2. Каждой ступени соответствует свой файл.

| Файл | Когда показывается | Что сейчас стоит |
|---|---|---|
| `stage_0` | игра ещё не начата | жёсткий диск на красном (`illustrations/18.1.png`) |
| `stage_1` | начат пролог | диск в руках (`illustrations/17.png`) |
| `stage_2` | начат Акт I | стена base64 со страницы «о сайте» (`documents/about_site.png`) |
| `stage_3` | начат Акт II | заплаканная Алиса (`illustrations/13.png`) |
| `stage_4` | начат Акт III | силуэт и «bellum omnium» (`illustrations/ren5.png`) |
| `stage_5` | игра пройдена | сад из финала (`illustrations/19.1.png`) |

Здесь лежат копии: картинки в `assets/old2023/images/` нужны сценарию и галерее, их не трогаем.

## Как поменять фон

1. Положите сюда картинку с именем нужной ступени: `stage_N.png`, `.jpg` или `.webp`. Старый файл удалите.
2. Откройте проект в редакторе Godot (или профиль «Редактор Godot» в Visual Studio), чтобы картинка импортировалась.

Подходят любые пропорции:
- широкая картинка (16:9) растягивается на весь экран;
- квадратная или вертикальная показывается справа целиком, на всю высоту, а за ней — её же затемнённая копия.

Если картинка слишком яркая или тёмная и мешает читать меню, яркость ступени настраивается
в массиве `Brightness` в `game/Menu/MenuBackdrop.cs`.

Если файла ступени нет, показывается фон предыдущей ступени.

Посмотреть любую ступень без прохождения (только отладочная сборка):

```bash
"E:/Game Engine/Godot Engine/Godot_v4.7.2-stable_mono_win64/Godot_v4.7.2-stable_mono_win64.exe" --path . -- --menu-stage=0
```
