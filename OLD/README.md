## Как устроен прототип

**Жанр (по itch.io):** триллер, повседневность, философия, психология. Статус Prototype, бесплатно.

**Завязка (по itch.io):** игрок получает посылку со старым жёстким диском. На диске наклейка с паролем и надписью «Не бойтесь». Игрок подключает его в виртуальной машине. В коде Ren'Py этой сцены нет — игра сразу начинается с BIOS.

**Подача:** вся игра — рабочий стол ретро-ОС в стиле Win95 (бирюзовый фон, 1280×720, пиксельный шрифт AcPlus_AST_PremiumExec):
- слева иконки `My PC` и `Recycle Bin` (показывают окно ошибки) и `Prolegomena.doc`;
- справа три архива `ACT1.zip`–`ACT3.zip` с паролями;
- снизу панель задач и `START` (открывает меню Ren'Py).

Текст идёт в окне-документе, иллюстрации показываются в отдельном окне-просмотрщике (`imageviewer`). Переходы сопровождаются глитч-эффектом слоя экранов.

**Поток игры:** BIOS (`bios2` → `bios1`) → рабочий стол → `Prolegomena.doc` → в конце картинка с паролем ACT1 → цепочка документов акта → в конце картинка с паролем следующего акта → … → финал (глаза Ренатуса, титры).

| Акт | Пароль | Документы (label в `script.rpy`) |
|---|---|---|
| — | — | `prolegomena` (FAQ сайта presentdays.org) |
| 1 | `Cogito, ergo sum` | `one_log` → `my_appeal` → `four_log` → `x_masgift` → `seven_log` → `mnogo_cifr` → `eight_log` |
| 2 | `Bellum omnium contra omnes` (или `Bellum omnium`) | `_02_05_1` → `_05_05_1` → `_06_05_1` → `_20_05_1` → `points` → `_21_05_1` |
| 3 | `Sum, ergo cogito` | `_25_05_1` → `short25` → `_26_05_1` → `_27_05_1` → `points1` → `_29_05_0001` → `_28_05_01` → `_29_05_1` → `_01_06_1` → `_02_06_1` → `end` |

Сюжет линейный, выборов нет. Единственное взаимодействие — пароли и клики по иконкам.
