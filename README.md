# GoliathChild:RE

Ремейк визуальной новеллы **Goliathchild** (LDJAM 2023, Ren'Py) на **Godot 4.7.2 .NET (C#)**.
В игру встроен редактор историй **GiC_OS**, в котором фанаты могут собрать свою историю в виртуальной ОС.

Версия: см. [VERSION](VERSION). Формат номера: `0.<этап>.<коммит>.<ММДД><a|b|s>`.

## Как запустить

1. Нужны Godot 4.7.2 **.NET** и .NET SDK 8 или новее.
2. Откройте `project.godot` в Godot или соберите и запустите из командной строки:

```bash
dotnet build GoliathChildRE.csproj
```

```bash
"E:/Game Engine/Godot Engine/Godot_v4.7.2-stable_mono_win64/Godot_v4.7.2-stable_mono_win64.exe" --path .
```

## Что уже работает (веха MVP)

- **Главное меню** в «киношном» стиле: История (продолжить / новая игра / загрузить / главы), Сохранения, Галерея, Своя история в GiC_OS, Настройки, Об игре, Выход.
- **Сюжет прототипа**: весь сценарий, все три акта на рабочем столе ОС.
  - Пароли архивов, «голоса» персонажей, глитч, окно просмотра, папки, окна ошибок.
  - Черновик нового пролога.
- **Сохранения как в Dishonored**: автосохранения в контрольных точках, быстрое (F5/F9), неограниченные ручные. Формат `.sdrom_save`.
- **Чтение**: откат назад (колесо мыши), журнал реплик (H), авточтение (A), пропуск прочитанного (Ctrl).
- **Настройки**: экран, графика, звук по каналам, скорость текста, режим светочувствительности, фильтр для дальтоников, язык, определение устройства ввода.
- **Редактор GiC_OS** в отдельном окне:
  - проекты, граф в стиле Blueprint, таймлайн, текст с подсветкой;
  - инспектор, проверка ошибок;
  - предпросмотр с любой метки, создание историй из шаблона.

## Правила кода

- Комментарии только на русском. Каждый фрагмент объясняет, что он делает и зачем.
- Интерфейс собирается кодом (`UiKit`), цвета лежат в `Palette`, шрифты — в `Fonts`.
- Сценарии — текст `.gics`. Граф и таймлайн редактора строятся из него.
