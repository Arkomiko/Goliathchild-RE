# Разбор прототипа Goliathchild (Ren'Py, 2023)

Ответ на вопросы 26 и 88. Разобрано всё содержимое папки игры, включая бонусные архивы и XmasGift.exe.
Исходники прототипа лежат локально в `.claude/old_gc/`, в репозиторий они не попадают.

## 1. XmasGift.exe — розыгрыш Rickroll

`game/XmasGift.exe` (7 МБ, SHA-256 `c06cdff2…a04dad6`) разобран статически, без запуска.

- Это скрипт на Python 3.8, упакованный PyInstaller. Собран 31.08.2023 на ПК пользователя `Zhenya`.
- Главный скрипт `XmasGift` делает одну вещь: `os.system("start https://www.youtube.com/watch?v=dQw4w9WgXcQ")`. Это открывает в браузере клип Rick Astley «Never Gonna Give You Up».
- В скрипте есть упоминание функции `timer` и путь `C:\Windows\System32\XmasGift.py` (путь сборки). Ничего вредного там нет.

**Смысл:** в сюжете XmasGift.exe — «объект №12», который Шилл рассылает команде и который ломает компьютер Алисы. В папке игры это шутка для игрока, который полезет запускать файл.

**Для ремейка:** вредоносный файл из сюжета повторяем внутри игровой ОС (безопасно). Настоящий `.exe` в папке игры можно оставить как пасхалку. Антивирусы иногда ругаются на сборки PyInstaller, поэтому лучше заменить его безопасным аналогом, например `.url`-ярлыком на тот же ролик.

## 2. Бонусные архивы ACT1–3.7z

Архивы зашифрованы AES. Пароли — игровые фразы, но в особом написании:

| Архив | Пароль | Содержимое |
|---|---|---|
| `ACT1.7z` | `cogito ergo sum` (строчные, без запятой) | `1_1.png`, `1_2.png` — письмо Geirby о сервере с оцифрованными книгами (13.09.2000): архив `Vatican_lib` (1032 МБ) от пользователя `Ioannes_Chrysostomus`, внутри «Оратор» Цицерона и неизвестный текст Гераклита на греческом |
| `ACT2.7z` | `bellum omnium` (строчные) | `2_1`–`2_4.png` — «Описание объекта №23 itsjust_a_burningmemory.org» |
| `ACT3.7z` | `SUM ERGO COGITO` (капс) | `3_1`, `3_2.png` — переписка Шопена с Ренатом |

Подробнее о содержимом ACT2 и ACT3:

- **ACT2 (объект №23).** Отчёт написан за Хилла. Сайт с тысячами папок по датам: 1917 год, «Курск» (12 августа), 11 сентября из «будущего», 2003, 2006, 2012. После 2035 года файлы не открываются. В конце — намёк на `bWFuZGVsYSBzZXJ2ZXI.bitnet`, это base64 от **`mandela server`**.
- **ACT3 (Шопен и Ренат).** Шопен объясняет, почему работает с «Эсхиллом» (SchHill). Рассказывает о пользователе **`ТЕХНОР-170619080715`**, который год назад на presentdays выдавал себя за систему инопланетной цивилизации. Приводится цитата его «ломаной» речи про корабль, ДНК и «100% мощность электричества мозга».

Тексты лежат в `.claude/old_gc/`.
В гайде с itch.io сказано: «пароли от архивов такие же, как в игре». Но на деле регистр и запятые отличаются — это тоже часть загадки.

**Для ремейка:** это готовый материал для «файлов в папке игры» и для скрытых документов внутри ОС. Хорошо ложится на ответ 25 (головоломки сложнее паролей).

## 3. Base64-строки в Prolegomena.doc

Темы форума presentdays.org закодированы в base64. Русский текст — в кодировке **KOI8-R**, а не UTF-8: это отдельный слой загадки, привет старому Рунету.

| Строка | Расшифровка |
|---|---|
| `DQrr0snQydDB09TZDQo=` | Крипипасты |
| `U2VyaWFsIEV4cGVyaW1lbnQgTGFpbg0K` | Serial Experiment Lain |
| `5NbPzs7JIO3Oxc3PzsnL` | Джонни Мнемоник |
| `5M/LyS3kz8vJIOzJ1MvM1cINCg==` | Доки-Доки Литклуб |
| `7snExMkg89TSyc3JDQo=` | Нидди Стрими |
| `6NzNySDJIMWjIMvPzdDYwNTF0s7B0SDUwNLY` + `zcENCg==` | Хэми и её компьютерная тюрьма |
| `DQriyc3CzyDTINTSxdTYyc0gx8zB2s/NLCDHzNHE0d3B0SDXIcLJztUg6c7UxdLOxdTB` | Бимбо с третьим глазом, глядящая в!бину Интернета |
| `IC0sICAgICAgICwgICAgIA==` | ` -,       ,     ` (пустышка из пробелов и запятых) |

В «Бимбо…» один байт испорчен: «в!бину» вместо «в глубину». Это либо намеренный глитч, либо опечатка при кодировании. Решение за сценаристами.

## 4. Механики сценария, которые должно уметь ядро

Всё, что реально используется в `script.rpy`, — минимальный набор для ядра GiC_OS.

| Механика в Ren'Py | Сколько раз | Аналог в GiC_OS |
|---|---|---|
| Реплика с тегами `{w=…}` (пауза), `{p=…}` (абзац + пауза), `{nw}`, `{b}`, `{i}`, `{size}` | ~1000 реплик, 984 `{p}`, 465 `{w}` | Свой разбор тех же тегов в печатной машинке |
| Персонаж с «голосом»: мелодия зациклена, пока печатается текст | 7 персонажей | Поле `voice` у персонажа |
| `$hai = "…"` — заголовок окна-документа | 22 | Команда `doc "…"` |
| Окно просмотра картинки `imageviewer` | 33 показа | `viewer show / hide` |
| Глитч слоя экранов (`Glitch(_fps=1000, glitch_strength=.3)` на 0.2 с) | 26 | `glitch 0.3 0.2` (шейдер) |
| Музыка: каналы `music1`, `ambient`, громкость, `fadeout` | 19 | `music` / `ambient` / `sound` |
| `pause N` | 32 | `pause N` |
| `scene` / `show` полноэкранных картинок `with dissolve` | ~5 | `scene` / `show` с переходами |
| `renpy.input` + проверка пароля | 3 | `input` + `if` с выражениями |
| Рабочий стол: иконки и архивы, разблокировка иконки, окно папки с файлом | — | ОС-команды `os.*` |
| Окно ошибки с картинкой (My PC, Recycle Bin) | 2 | `os.error` |
| `jump` / `call` / `return` | ~40 | так же |
| Финальные титры, `renpy.quit()` | 1 | `end` |

Выборов (`menu`) в прототипе нет. Ветвления появятся с новым сценарием.
