# Формат сценариев GiC_OS (.gics)

`.gics` (GiC Script) — текстовый формат историй GoliathChild:RE и редактора GiC_OS.
Он похож на Ren'Py, поэтому сценарий прототипа 2023 года перенесён почти без изменений.
Граф и таймлайн в редакторе строятся из этого текста: текст — источник истины.

## Основы

- Одна строка — одна команда. Вложенность задаётся отступом в 4 пробела (табуляция тоже считается за 4).
- `#` после пробела или в начале строки — комментарий. Исключение: `color=#2c99a3` — это цвет.
- Строки пишутся в двойных кавычках. Внутри работают `\n` (перенос), `\"` (кавычка) и `\\`.
- Числа пишутся с точкой: `0.3`.
- Параметры: позиционные (`glitch 0.3 0.2`) или именованные (`glitch strength=0.3 time=0.2`).

```
# Персонажи и переменные объявляются вне меток
character ch "[doc]" color=#000000 voice="old2023/audio/voices/Chopin.ogg"
var password = ""

label start:
    doc "4.log"
    glitch 0.3 0.2
    music "old2023/audio/music/PixWho_i_2.ogg" volume=0.3
    ch "Chopin: Ты на связи?{p=0.3}"
    "Реплика рассказчика"
    jump next_label
```

## Верхний уровень файла

| Команда | Что делает |
|---|---|
| `label имя:` | Метка — кусок сценария и узел графа. Без `jump`/`return`/`end` в конце выполнение переходит в следующую метку файла (как в Ren'Py). |
| `character id "Имя" [color=#hex] [voice="файл"] [voice_volume=1] [sprite="файл"] [sprite_эмоция="файл"] [info="заметки"]` | Персонаж. Имя может содержать переменные: `"[doc]"` — в заголовке окна будет имя документа. `voice` — мелодия, которая звучит, пока печатается реплика. |
| `var имя = выражение` | Переменная со значением по умолчанию. |

## Реплики и текст

| Команда | Что делает |
|---|---|
| `"текст"` | Реплика рассказчика. |
| `id "текст"` или `say id "текст"` | Реплика персонажа. |
| `centered "текст"` | Реплика по центру экрана без окна (встроенный рассказчик, как в Ren'Py). Текст целиком плавно появляется, ждёт клика и плавно гаснет. Цвет букв подбирается к фону: на светлом сплошном фоне чёрный, иначе белый. |
| `doc "название"` | Заголовок окна-документа (переменная `doc`). |
| `notify "текст"` | Всплывающее уведомление у трея. |

Теги внутри текста:

| Тег | Смысл |
|---|---|
| `{w=0.3}` / `{w}` | Пауза на 0.3 с / ждать клика. |
| `{p=0.3}` / `{p}` | Перенос строки после паузы / после клика. |
| `{nw}` | Не ждать клика после реплики. |
| `{b}…{/b}`, `{i}…{/i}`, `{u}…{/u}`, `{s}…{/s}` | Жирный, курсив, подчёркнутый, зачёркнутый текст. |
| `{size=40}…{/size}`, `{color=#ff0000}…{/color}` | Размер и цвет. |
| `[переменная]` | Подстановка значения переменной. |
| `[[`, `{{` | Сами символы `[` и `{`. |

## Картинки и экран

| Команда | Что делает |
|---|---|
| `scene "файл" [transition=dissolve\|fade\|none] [time=0.5]` / `scene none` | Фон. Вместо файла можно указать цвет: `scene "#ffffff"` — белый экран для заставок с `centered`. |
| `show метка "файл" [x=0.5 y=0.5] [transition=…] [time=…]` | Картинка поверх рабочего стола (BIOS, титры, спрайт). `x` и `y` — центр картинки в долях экрана. |
| `hide метка [transition=…]` | Убрать картинку. |
| `viewer "файл" [wait]` / `viewer hide` | Окно просмотра картинки. С `wait` история ждёт, пока игрок закроет окно. |
| `glitch [сила=0.3] [время=0.2]` | Глитч-эффект. |
| `shake [сила=12] [время=0.4]` | Тряска экрана. |
| `flash [#цвет] [время=0.3]` | Вспышка. |

В режиме светочувствительности игра автоматически смягчает глитч, тряску и вспышки.

## Звук

| Команда | Что делает |
|---|---|
| `music "файл" [volume=1] [loop=true] [fadein=0]` | Музыка (по умолчанию зациклена). |
| `ambient "файл" …` | Фоновый звук (зациклен). |
| `sound "файл" …` | Разовый звук. |
| `voice "файл" …` | Озвучка. |
| `stop music\|ambient\|sound\|voice\|all [fadeout=1]` | Остановить канал. |
| `pause [секунды]` | Пауза. Без числа — до клика. |

## Логика

| Команда | Что делает |
|---|---|
| `jump метка` / `call метка` / `return` | Переход, вызов с возвратом, возврат. |
| `set имя = выражение` или `$ имя = выражение` | Присвоение. Работают `+=`, `-=`, `*=` и `/=`. |
| `if выражение:` / `elif …:` / `else:` | Условие. |
| `menu "Вопрос":` + варианты `"Текст" [if условие]:` | Выбор игрока. |
| `input переменная "Подсказка" [default=""] [max=64]` | Ввод текста (пароли). |
| `checkpoint id "Название"` | Автосохранение и открытие главы в меню «История». |
| `end` | Конец истории. |

Выражения пишутся в синтаксисе GDScript: `and`, `or`, `not`, `==`, `!=`, `<`, `+`, методы строк (`answer.to_upper()`).
Дополнительные функции:

| Функция | Что возвращает |
|---|---|
| `normalize(s)` | Строку в нижнем регистре без знаков препинания (ё → е). Удобно для паролей. |
| `lower(s)`, `upper(s)` | Строку в нижнем / верхнем регистре. |
| `contains(s, часть)` | Есть ли подстрока (без учёта регистра). |
| `length(s)` | Длину строки. |
| `rand(a, b)` | Случайное целое от `a` до `b`. |
| `chance(p)` | Случайное событие с вероятностью `p`. |
| `visited("метка")` | Посещал ли игрок метку. |

## Виртуальная ОС

| Команда | Что делает |
|---|---|
| `os desktop show\|hide [wallpaper="файл"]` | Показать / скрыть рабочий стол. |
| `os icon id ["Подпись"] [image=] [side=left\|right] [action=метка] [error="картинка"] [hidden=true]` | Иконка. Повтор с тем же `id` меняет только указанные поля. `action=none` убирает действие. Под новыми иконками игра сама пишет подпись; у иконок из `old2023/` она нарисована на картинке. |
| `os remove id` | Удалить иконку. |
| `os folder id "Название"` | Папка (архив). |
| `os file папка id "Название" [image=] [action=метка]` | Файл в папке. |
| `os open папка` / `os close` | Открыть / закрыть окно папки. |
| `os error "картинка"` или `os error "Заголовок" "Текст"` | Окно ошибки. |
| `os clock "23:41"` | Текст часов на панели задач. |
| `os wait` | Ждать клика игрока по иконке или файлу. История перейдёт к метке из `action`. |

Готовый пример — `stories/example_story/main.gics`. Полный сюжет — `scenarios/goliathchild/`.

## Ассеты

Пути ищутся сначала в папке `assets/` самой истории, потом во встроенных ассетах игры (`res://assets/`).

- Картинки — PNG или JPG.
- Звуки — OGG.
- Картинки из `old2023/` нарисованы под 720p и автоматически увеличиваются в 2 раза. Новые ассеты рисуйте под 2560×1440.
